# الخيال للخدمات المنزلية

موقع عربي متجاوب من اليمين إلى اليسار لخدمات المنزل. الصفحات: الرئيسية، من نحن، خدماتنا، المقالات، اتصل بنا، وصفحة الفيديو. يعمل الموقع كملفات HTML/CSS/JS ثابتة ويُنشر تلقائيًا عبر GitHub Pages عند الدفع إلى فرع `main`.

## تشغيل محلي

افتح `index.html` مباشرة، أو شغّل خادمًا ثابتًا داخل المجلد:

```bash
python3 -m http.server 8000
```

## الصور

الصور الحالية في `images/` صور مؤقتة مخصصة للموقع. روابط ImgBB التي وردت في الطلب أعادت في بيئة التنفيذ صفحة «That page doesn't exist (404)»، لذا لم أضعها في الموقع كصور معطوبة. عند إرسال الصور الأصلية، استبدل ملفات الصور مع الاحتفاظ بالأسماء أو حدّث المسارات في HTML.

## خلفية Aurora

يحتوي `source/aurora-background.tsx` على مصدر المكوّن كما نُشر في Opensource UI، وتعيد `styles.css` تنفيذ طبقاته المرئية للموقع الثابت. حُذفت عبارة المعاينة الوسطى فقط. إشعار MIT الكامل محفوظ في `LICENSES/aurora-background-MIT.txt`.

## النشر

ملف `.github/workflows/pages.yml` يبني وينشر ملفات الموقع إلى GitHub Pages مع كل تحديث لفرع `main`.
